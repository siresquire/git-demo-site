# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

A static training site used to practice Git/GitHub workflows (branching, commits, amends, etc.). Plain HTML/CSS, no build step, no framework.

## Commands

- `npm start` — serves the site locally via `http-server .`

There is no lint, build, or test tooling in this repo.

## Structure

- `index.html` — single page, entry point
- `css/style.css` — page styles

## Standing orders

- Do not add a `Co-Authored-By` line (or any AI attribution) to commit messages in this repo. Commits should show the user as sole author.
